# CONTROL12 Sovereign Fabric v2.0.0

CONTROL12 Sovereign Fabric is the advanced control plane for governed AI operations across local, cloud, edge, cluster, and disconnected execution domains.

The runtime provides tenant-scoped authorization, hash-chained audit events, durable DAG workflows, worker leases, approval gates, artifact provenance, signed plugin manifests, digest-only deployment plans, metrics, Kubernetes, Supabase, and GHCR release paths.
