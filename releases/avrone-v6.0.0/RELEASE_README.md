# Avrone Sovereign Fabric v6.0.0

Avrone v6 introduces a sovereign institutional operating network:

- Three-authority constitutional policy activation
- Quorum-based amendments with independent activation
- Bounded delegated-authority leases
- Fail-closed emergency authority
- Append-only SHA-256 institutional event log
- Merkle checkpoints
- Treaty-governed federation missions
- Deterministic audit exports
- Independently reviewed accounting reconciliation
